# THRM-SYNC (`thrm-sync-pcb`)

Custom multi-channel PWM heater driver and telemetry PCB designed for HVAC thermal synchronization experiments.

---

## Overview
**THRM-SYNC** regulates resistive heating loads using 5V logic-level PWM switching and provides real-time telemetry over I2C. It is built for benchtop HVAC lab testing to study heat transfer, thermal mass behavior, and multi-zone synchronization.
